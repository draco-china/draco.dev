# macOS application icons

Exported from this Mac running macOS 26.6.2 (25G83), using sips to export the application ICNS resources. Dock icons are resized to 192 × 192 and encoded as quality-90 WebP with full-quality alpha, covering the displayed size at up to 3× pixel density. Original application files are unchanged. See provenance.json for application paths and versions.

Safari, Music, System Settings and Visual Studio Code represent their corresponding applications. Contacts represents About, Apps represents Navigation, Automator represents Tools, and Home represents the desktop. Artwork and trademarks belong to their respective owners.

The UI preserves the exported silhouette, padding and shading without adding another icon background or rounded clipping mask.

Window control backgrounds were rendered from AppKit NSWindow standardWindowButton on the same system at 2x, with a 14-point canvas. Hover glyphs remain SVG overlays.

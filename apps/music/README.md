# 音乐应用

桌面与独立站复用同一 Qwik 组件，音频实例由音乐应用持有，桌面关闭窗口后继续播放。应用使用共享 `public/music` 静态目录，部署无需音乐 API、登录账号或服务端凭据。

## 静态目录契约

`/music/catalog.json` 格式为 `{ "version": 1, "songs": [] }`。每首真实文件对应 `StaticSong`：

- `id`：稳定、安全整数，同一音频文件重新扫描后保持一致
- `title`、`artists`、`album`：字符串元数据
- `duration`：秒数
- `src`：同源音频 URL，例如 `/music/audio/song.mp3`
- `cover`：同源封面 URL，无封面使用空字符串
- `lyrics`：可选 LRC 文本，直接内嵌文本而非文件 URL

`src` 和 `cover` 支持 URL 编码的路径。目录加载时验证版本、重复 ID、时长与 URL；搜索在已加载目录中匹配歌曲、作者和专辑，播放直接读取静态音频，歌词本机解析。没有实际文件时保持空目录。

## 本机播放状态

IndexedDB 保存队列、最近播放、索引、进度、音量和模式。成功载入目录后按 ID 将旧记录对齐到当前元数据，移除目录中不存在的歌曲；当前歌曲仍存在时保留进度，否则归零。目录加载失败时保留已有记录并提供重试。

进入桌面后后台准备同一个音乐实例并尝试播放，保持窗口隐藏与当前 URL；音乐小组件直接控制该实例，打开音乐窗口继续复用。空队列初始化为当前完整目录；有效旧队列优先恢复。初次准备及恢复完成后只自动尝试一次，浏览器要求用户操作时提供播放入口。目录刷新不会重新启动用户已暂停的音频。每 5 秒、暂停及调整进度时保存，存储不可用时保留当前会话。

## 界面

许嵩播放列表、顶部本机搜索、底部播放器构成主界面。展开播放器提供进度、音量、播放模式和歌词；颜色继承站点主题与强调色。最近播放仅作为本机记录维护。

## 验证

Vitest 验证目录校验、同源资源、本机搜索、歌词解析和旧记录对齐；Browser Mode 使用生成的 WAV 静态资源验证真实播放、暂停、进度、背景小组件和响应式播放器。测试曲目仅存在于测试 fixture，不写入公共歌曲目录。
